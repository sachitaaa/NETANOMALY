# NetAnomaly

Machine Learning-Based Network Anomaly Detection System

## Project Goal

NetAnomaly is a machine learning project that analyzes network traffic
and detects whether the traffic is normal or anomalous.


## Project Overview

NetAnomaly is an experimental machine learning project focused on detecting anomalous network traffic using the CIC-IDS2017 dataset. It explores Random Forest classification, feature analysis, and model evaluation across different network attack types.

The project investigates an important challenge in intrusion detection: a model that performs well on familiar traffic may fail to recognize previously unseen attack types.

## Future Work

- Establish a reliable training, validation, and final testing strategy.

- Develop a reusable prediction pipeline.
- Build a simple interface for demonstrating predictions.
